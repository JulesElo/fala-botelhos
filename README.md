## Sobre o projeto

Ao longo de quatro etapas, o grupo analisou os problemas urbanos de Botelhos, um município de pequeno porte do Sul de Minas, e propôs o **Fala, Botelhos**: uma plataforma que combina um aplicativo com encontros presenciais para que o morador possa:

- **Reportar** problemas da cidade, como buracos e calçadas sem acessibilidade, e acompanhar cada etapa até a resolução;
- **Decidir**, em consultas semestrais, as prioridades dos investimentos maiores;
- **Participar presencialmente**, nos bairros e distritos, mesmo sem smartphone.

## Protótipo

Uma versão navegável da plataforma, feita para demonstrar a proposta. As ruas e os bairros são reais; os pedidos, votos e números são fictícios.

- **Mapa de pedidos:** problemas relatados, com etapas, prioridade e apoios.
- **Reportar:** registro de um novo problema com foto e local.
- **Decidir:** consulta semestral sobre as prioridades de investimento.
- **Transparência:** indicadores públicos da plataforma.

Feito com HTML, CSS e JavaScript puros, sem frameworks nem instalação. Para rodar no seu computador, abra `prototipo/index.html` no navegador.
